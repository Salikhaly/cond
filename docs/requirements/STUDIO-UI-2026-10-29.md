# COND — визуальная иерархия и ежедневные действия

29 октября 2026. Продолжение существующего интерфейса, без замены учёта или переноса рабочих документов.

## Что изменилось

- Главная «Мой цех»: дата, четыре цветных действия, одна заметная задача, продажи с графиком, прибыль, расходы и долги. На ноутбуке продажи, прибыль и расходы располагаются рядом; на телефоне — последовательно.
- График строится по реальным строкам продаж за выбранный период, включает возвраты и дни без продаж. Периоды больше 62 дней группируются по месяцам. Из карточки открывается отчёт по клиентам с теми же датами. Неизвестная прибыль остаётся «Нужна сверка».
- Кнопка поиска в шапке: действия, разделы и материалы с остатками. Поиск учитывает доступные пользователю разделы; переход к материалу сразу фильтрует склад. Закрытие через Escape возвращает фокус.
- Расход: крупная сумма, частые статьи, выбор категории и подкатегории, компактная строка выбранной статьи. Платёжные счета появляются после выбора статьи. Кнопка сообщает, что ещё нужно заполнить. Поиск статьи раскрывается по кнопке.
- Приход: шаги «Поставщик → Материалы → Оплата». Названия вкладок помещаются на телефоне без разрыва слов. Поиск умеет повторно открыть приход даже из другого режима склада.
- Заявка: на подтверждении видны только заказ и его данные. Товары представлены компактными строками с фото, весом, ценой за кг и суммой. Каталог возвращается по кнопке «Изменить».
- Исправлен потерянный параметр перехода в отчёты: Finance теперь получает intent из Workspace. Раньше отчёт мог открываться за семь дней вместо периода главной.
- Поиск выпуска и прихода корректно работает при повторном обращении внутри уже открытого раздела.

## Проверка

Изолированная база `cond_public_demo_test_1793290178198`, API 3005, веб 9001. Telegram отключён. В ней проверены сохранение расхода 2 000 ₸, приход 10 кг × 300 ₸ с оплатой 1 000 ₸ и долгом 2 000 ₸, отправка заявки 3 кг на 6 200 ₸, возврат к редактированию, сохранение даты при обычном клавиатурном вводе. Рабочая база не использовалась для этих операций.

- 18 проверок изолированного демо API.
- 86 компонентов: проверка порядка React Hooks.
- 9 проверок реальных рядов графика, возвратов, пустых дат и ограничения поиска по роли.
- 8 проверок денежных отчётов.
- Сборки локальной и публичной версий: успешно; три прежних предупреждения Webpack о размере/организации сборки.
- Интерфейс проверен на 390 × 844 и 1360 × 900; основные проверенные формы без горизонтальной прокрутки. Проверены поиск, фокус, роли работника и представителя, мобильная заявка и переходы владельца.
- Финансовая сверка отдельной базы после UI-операций: `ok: true`.

Автоматизация браузера при fill поля даты меняет DOM-значение без React-события. Проверка выполнена обычным клавиатурным вводом: дата сохраняется после возврата к каталогу и повторного открытия формы. Код даты не менялся.
