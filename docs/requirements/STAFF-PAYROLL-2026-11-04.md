# Сотрудники, задания и зарплата — 04.11.2026

По последнему решению владельца публичное демо сохраняется. Перевод в закрытый рабочий режим и смена общих логинов в этот выпуск не входят. Почта пока остаётся явной заглушкой.

## Пользовательские изменения

- Настройки → Пользователи → «Показывать заявки» у выбранного работника. По умолчанию выключено. Сотрудник видит «Что готовить» в своей выработке: товар, фасовку, количество, срок, остаток и потребность. Цены, клиенты, телефоны и чужая зарплата в эту проекцию API не попадают.
- В плане учитываются новые и согласованные заявки: согласование сейчас требует наличия продукции, поэтому исключение новых заявок скрывало бы всю потребность в изготовлении. Неподтверждённые заявки явно отмечены. Это общий план цеха, не персональное назначение партии; сотрудник записывает только свой фактический выпуск.
- Настройки → Добавить сотрудника: создание доступа с паролем или приглашение на email. При отключённой почте интерфейс прямо сообщает об этом; можно пользоваться обычным созданием доступа.
- На входе — «Забыли пароль?». Пока почта не подключена, показана заглушка. Реальный механизм подготовлен: одноразовая ссылка, 30 минут для сброса / 48 часов для приглашения, в БД только хеш токена, завершение предыдущих сеансов после сброса. Приглашения создаёт владелец, доступные роли — работник и представитель. Реальная доставка писем не проверена и не включена.
- Настройки связываются с экранами по постоянным ключам: названия больше не зависят от количества условно отображённых блоков. При открытом меню «Ещё» нижняя панель действий скрывается и не перекрывает последний пункт. Работнику не показываются быстрые кнопки чужих разделов.

## Зарплата

- «Месячный оклад» для работника теперь можно реально начислить через месячный расчёт, ответ сотрудника и проведение администратором; спор решает владелец с сохранением истории.
- Сохранённая сумма оклада сама по себе не является начислением и больше не прибавляется интерфейсом поверх зарплатного журнала.
- Оклад берётся из согласованных условий. Повторный расчёт начисляет только разницу; повтор без изменений не создаёт вторую зарплату. Выпуск при месячном окладе не добавляет сдельную оплату.
- Неполный месяц, премии и удержания оформляются отдельной согласованной корректировкой. Автоматический расчёт по рабочим дням не введён без утверждённого правила бизнеса. Месячный режим начинается с первого числа.
- Сдельные ставки, смены, ежедневные проценты, месячные проценты представителя от отгрузок/оплат/маржи и подтверждённой прибыли сохранены. Авансы уменьшают сумму к выдаче, включая выдачу вперёд при подтверждении администратора.

## Исправления проверок

- История выбранного денежного счёта сохраняет переводы, а их сумма не попадает в операционные расходы.
- Сверка отгрузок понимает актуальные связи с фасовкой и цену за коробку; старые связи сохранены.
- Проверка прав прошлой даты для инвентаризации применяется и к `/accept`.
