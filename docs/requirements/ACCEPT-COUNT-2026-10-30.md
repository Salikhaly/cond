# Приём фактических остатков — 30.10.2026

Одна кнопка «Принять остатки» атомарно сохраняет введённый факт и проводит инвентаризацию. Второй экран подтверждения не нужен. Принимаются только заполненные позиции: пустое поле не изменяет склад, ноль означает отсутствие товара. Пропущенные позиции записаны в журнале происхождения; повторного пересчёта по ним система не требует.

Неизвестная закупочная цена не блокирует излишек или недостачу. Количество принимается, денежная стоимость остаётся неизвестной. В главном отчёте вместо общей тревоги «Нужна сверка» показано «Не рассчитана»; принятая инвентаризация не предлагается к повторному проведению из-за отсутствия стоимости.

Проверяются права, версия самого документа, реальные изменения количества склада и резерв по заявкам. Изменение только служебной метки или оценки без движения количества не требует повторного подсчёта. Повторный запрос с тем же номером возвращает прежний результат; незаполненный пересчёт не проводится.

23 проверки на изолированной базе: излишек и недостача без цены, единичное проведение/повтор, частичный ввод и сохранность пропущенных позиций, откат при конфликте резерва, неизменность зарплаты и продаж, сверка количеств и стоимости. Неизвестные цены не подменяются нулевой себестоимостью.

Релиз: READY dpl_5HjeQXDY7q6DoYzYsTmxBB6tS2pD, https://cond-demo.vercel.app/. В браузере на отдельной базе подтверждено: из 3 выбранных позиций введена одна, излишек 7 кг без цены принят одним нажатием; остальные 70 и 30 кг не изменены. Сверка API проходит. Все 23 проверки серверной инвентаризации, проверка порядка hooks 94 компонентов и обе production-сборки прошли. Реальных тестовых изменений в общей демобазе не выполнялось.
