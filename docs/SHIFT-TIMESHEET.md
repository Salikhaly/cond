# Табель и индивидуальные ставки

В зарплате сотрудника доступны «За день / смену», «По изготовленным кг» и «Смена + выработка». Месячные варианты сохраняются.

Администратор открывает сотрудника → условия оплаты → «Изменить оплату и ставки». Для смены задаётся стандартная сумма; для выработки можно добавить персональную ставку за каждый товар. Условия проходят существующее согласование с сотрудником.

В табеле нажмите на день: работал, выходной, больничный, отпуск или не вышел. При сменной оплате можно указать отдельную сумму дня. Больничный по умолчанию равен нулю; сумму задаёт администратор, автоматический нормативный расчёт не выполняется.

Сотрудник отправляет только собственную отметку за сегодня. До подтверждения она не начисляет зарплату. Проведённый выпуск подтверждает рабочий день; противоречащую ему нерабочую отметку сохранить нельзя.

Смена начисляется один раз за день, выработка — по проведённым актам. Повторное сохранение не добавляет вторую смену. Изменения начисленной суммы сохраняются в истории; уменьшения проходят существующее согласование/решение владельца. Персональная ставка фиксируется в проведённом выпуске и не меняет прошлые документы.

Проверено на отдельной базе: 43 сценария дневной оплаты и согласований, 20 сценариев оклада с выработкой; 25 проверок календаря и расчётов интерфейса. Рабочая база не использовалась для тестовых начислений.
